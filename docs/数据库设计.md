# Manner_Web 数据库设计

> 本文件以 `backend/sql/init.sql` 为**唯一权威依据**，2026-08 核对（权限系统重构为 RBAC + 数据范围 + 部门角色继承后修订）。
> 相关文档：[权限系统设计.md](./权限系统设计.md) · [API文档.md](./API文档.md)。

---

## 一、概述

- 数据库：MySQL 8；字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`；存储引擎 InnoDB。
- 主键约定：
  - 业务实体（员工、会话、消息、拉黑、角色、部门）用 `CHAR(36)` UUID 主键，由应用层生成；
  - `permissions` 用自增 `INT`；
  - `system_settings` 用业务字符串键（`setting_key`）；
  - `super_admin` 内置角色使用固定 UUID `00000000-0000-0000-0000-000000000001`。
- 时间约定：时间列使用 `DATETIME`；`created_at` 默认 `CURRENT_TIMESTAMP`；`updated_at` 带 `ON UPDATE CURRENT_TIMESTAMP` 自动更新。
- **共 16 张表**，分六组：

| 分组 | 表 |
| --- | --- |
| 组织与账号 | employees |
| 权限（RBAC） | permissions、roles、role_permissions、employee_roles、department_roles、role_department_scopes |
| 会话安全 | token_blacklist |
| 聊天 | conversations、conversation_participants、messages、blocked_users |
| 组织架构 | departments、employee_departments、department_leaders |
| 系统配置 | system_settings |

> **员工级直接授权表 `employee_permissions` 已彻底移除**。存量数据库升级时由 `main.rs::migrate_direct_permissions` 迁移（持有全部存量权限 → super_admin；部分权限 → 私有角色）后删除该表。

## 二、表结构

### 2.1 employees（员工账号）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| username | VARCHAR(64) | UNIQUE, NOT NULL | 登录用户名 |
| password | VARCHAR(255) | NOT NULL | bcrypt 哈希（cost 12），不存明文 |
| name | VARCHAR(64) | NOT NULL | 姓名 |
| title | VARCHAR(64) | NULL | 职位 |
| email | VARCHAR(255) | NULL（加密） | 邮箱（静态加密 enc:v1: 密文） |
| phone | VARCHAR(255) | NULL（加密） | 电话 |
| id_number | VARCHAR(255) | NULL（加密） | 身份证号 |
| address | TEXT | NULL（加密） | 地址 |
| hire_date | DATE | NULL | 入职日期 |
| status | TINYINT | NOT NULL DEFAULT 1 | 1 启用 / 非 1 禁用（见「特殊字段语义」） |
| pwd_version | INT | NOT NULL DEFAULT 0 | 密码版本号（改密递增，全端踢出） |
| must_change_password | TINYINT | NOT NULL DEFAULT 0 | 1=首登强制改密 |
| active_session | VARCHAR(64) | NULL | 当前有效会话 id（单设备登录） |
| preferences | TEXT | NULL | 个人偏好 JSON（白名单 schema） |
| perm_version | INT | NOT NULL DEFAULT 0 | **权限版本号**：权限相关变更递增，令牌失效重算（见「特殊字段语义」） |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| avatar | VARCHAR(255) | NULL | 头像 URL（/uploads/...） |
| updated_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

索引：`PRIMARY KEY(id)`、`UNIQUE(username)`、`idx_status(status)`、`idx_name(name)`。**无外键**。

### 2.2 permissions（权限字典）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | INT | AUTO_INCREMENT PK | 自增主键 |
| code | VARCHAR(64) | UNIQUE, NOT NULL | 权限码，如 employee:list |
| name | VARCHAR(64) | NOT NULL | 权限名称 |
| module | VARCHAR(32) | NOT NULL | 所属模块（employee/department/role/chat/system） |

种子数据（`INSERT IGNORE`，共 18 条），按模块：

| code | name | module |
| --- | --- | --- |
| employee:list / view / create / edit / delete / password / view_sensitive | 员工管理 7 项 | employee |
| department:list / view / create / edit / delete | 部门管理 5 项 | department |
| role:manage | 角色管理 | role |
| chat:protect_block / group_create / upload | 聊天 3 项 | chat |
| system:config / settings | 系统 2 项 | system |

> 旧的 `employee:protect_block` 已被移除（`DELETE FROM permissions WHERE code='employee:protect_block'`），防拉黑保护统一使用 `chat:protect_block`。

### 2.3 roles（角色）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键（super_admin 固定 id `00000000-0000-0000-0000-000000000001`） |
| name | VARCHAR(64) | UNIQUE, NOT NULL | 角色名称 |
| parent_id | CHAR(36) | NULL | 父角色（角色继承链，防环） |
| is_system | TINYINT | NOT NULL DEFAULT 0 | 1=内置（super_admin），不可删除/改权限/改范围 |
| scope_type | VARCHAR(16) | NOT NULL DEFAULT 'self' | all/subtree/department/self/custom |
| description | VARCHAR(255) | NULL | 描述 |
| created_at / updated_at | DATETIME | 默认 | 时间戳 |

索引：`UNIQUE(name)`、`idx_parent(parent_id)`。

种子：`super_admin`（id 固定、is_system=1、scope_type=all、全量权限，`INSERT IGNORE` 幂等）。

> 角色编码（code）已移除：角色以唯一名称 + id 标识；super_admin 用固定 id 特判（见 `权限系统设计.md` §3）。

### 2.4 role_permissions（角色-权限 多对多）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| role_id | CHAR(36) | NOT NULL, 联合 PK | 角色 ID |
| permission_id | INT | NOT NULL, 联合 PK | 权限 ID |

外键：`role_id → roles(id) ON DELETE CASCADE`、`permission_id → permissions(id) ON DELETE CASCADE`。

### 2.5 employee_roles（员工-角色 多对多，直接分配）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| employee_id | CHAR(36) | NOT NULL, 联合 PK | 员工 ID |
| role_id | CHAR(36) | NOT NULL, 联合 PK | 角色 ID |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 分配时间 |

外键：双 `ON DELETE CASCADE`。

### 2.6 department_roles（部门-角色 多对多，部门角色继承）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| department_id | CHAR(36) | NOT NULL, 联合 PK | 部门 ID |
| role_id | CHAR(36) | NOT NULL, 联合 PK | 角色 ID |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 绑定时间 |

外键：双 `ON DELETE CASCADE`。员工归属部门后自动获得该部门绑定角色权限（仅直接归属，不级联子部门）。

### 2.7 role_department_scopes（角色 custom 范围明细）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| role_id | CHAR(36) | NOT NULL, 联合 PK | 角色 ID |
| department_id | CHAR(36) | NOT NULL, 联合 PK | 部门 ID |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 绑定时间 |

外键：双 `ON DELETE CASCADE`。仅 `scope_type=custom` 时使用。

### 2.8 token_blacklist（令牌黑名单）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| jti | VARCHAR(255) | UNIQUE, NOT NULL | JWT 的 jti 声明（登出/轮换时记录） |
| expires_at | DATETIME | NOT NULL | 令牌过期时间（黑名单条目过期即失效） |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 记录时间 |

索引：`idx_jti(jti)`、`idx_expires_at(expires_at)`。独立表，无外键。

### 2.9 conversations（会话）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| type | VARCHAR(16) | NOT NULL DEFAULT 'single' | single=单聊 / group=群聊 |
| name | VARCHAR(128) | NULL | 群聊名称（单聊为 NULL） |
| created_by | CHAR(36) | NULL | 创建者员工 ID（逻辑引用） |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.10 conversation_participants（会话参与人）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| conversation_id | CHAR(36) | NOT NULL, 联合 PK | 会话 ID |
| employee_id | CHAR(36) | NOT NULL, 联合 PK | 员工 ID |
| joined_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 加入时间 |
| role | VARCHAR(16) | NOT NULL DEFAULT 'member' | member / admin（群管理员） |
| nickname | VARCHAR(64) | NULL | 本会话内昵称 |
| group_note | VARCHAR(255) | NULL | 我为对方设置的单聊备注 |

### 2.11 messages（消息）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| conversation_id | CHAR(36) | NOT NULL | 所属会话（逻辑引用） |
| sender_id | CHAR(36) | NOT NULL | 发送者员工 ID（逻辑引用） |
| type | VARCHAR(16) | NOT NULL DEFAULT 'text' | text / file |
| content | TEXT | NULL | 文本内容 |
| file_url | VARCHAR(512) | NULL | 文件消息链接（/uploads/chat/...） |
| file_name | VARCHAR(256) | NULL | 原始文件名 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 发送时间 |

索引：`idx_conversation_time(conversation_id, created_at)`。

### 2.12 system_settings（系统设置）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| setting_key | VARCHAR(64) | PK | 业务字符串键 |
| setting_value | TEXT | NOT NULL | 值 |
| updated_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

种子键（`INSERT IGNORE`）：

| setting_key | 默认值 | 说明 |
| --- | --- | --- |
| registration_open | '1' | 首个管理员注册开关（注册成功后置 '0'） |
| default_language | 'en-US' | 默认语言（system / en-US / zh-CN） |
| login_max_failures | '5' | 登录限流阈值（环境变量兜底） |
| login_lock_window_secs | '900' | 限流窗口秒数（环境变量兜底） |

其余键（`chat_upload_limit`、`login_theme`、`site_title`、`login_site_title`、`login_site_icon`、`site_icon`）由 `PUT /api/system/settings` 按需写入。

### 2.13 blocked_users（拉黑关系）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| blocker_id | CHAR(36) | NOT NULL, 联合 PK | 拉黑发起者 |
| blocked_id | CHAR(36) | NOT NULL, 联合 PK | 被拉黑者 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 拉黑时间 |

### 2.14 departments（部门）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| name | VARCHAR(64) | NOT NULL | 部门名称 |
| parent_id | CHAR(36) | NULL | 上级部门（树形，防环） |
| leader_id | CHAR(36) | NULL | 部门负责人（逻辑引用，历史字段） |
| sort_order | INT | NOT NULL DEFAULT 0 | 排序 |
| created_at / updated_at | DATETIME | 默认 | 时间戳 |

索引：`idx_parent(parent_id)`。

### 2.15 employee_departments / department_leaders

- `employee_departments(employee_id, department_id)`：员工-部门多对多归属（一个员工可加入多个部门），双 FK 级联。
- `department_leaders(department_id, employee_id)`：部门负责人多对多（一个部门可有多个负责人），双 FK 级联。

## 三、表间关系

```
roles ──< role_permissions >── permissions     （角色-权限 多对多，双 FK CASCADE）
roles ──< employee_roles >── employees         （员工分配角色）
roles ──< department_roles >── departments     （部门绑定角色）
roles ──< role_department_scopes >── departments（custom 数据范围）
departments ──< employee_departments >── employees（员工归属部门）
departments ──< department_leaders >── employees（部门负责人）
conversations ──< conversation_participants >── employees
conversations ──< messages
blocked_users（双向语义）
token_blacklist（独立）
system_settings（键值表）
```

- **角色继承**：`roles.parent_id` 自引用；解析时沿父链向上展开。
- **有效授权** = 员工直接角色 ∪ 所属部门绑定角色（含各自父链继承），`services/permission.rs::resolve_effective_grants` 用 `WITH RECURSIVE` 实现。

## 四、迁移机制

- 后端启动执行 `run_migrations`：读取 `backend/sql/init.sql`，按 `;` 分号分割逐条执行；跳过 `CREATE DATABASE` / `USE`。
- 单条语句失败**仅 warn 不中断**（存量库可继续启动）。注意：`ALTER TABLE ... DROP COLUMN protect_block` 与 `ALTER TABLE roles DROP COLUMN code` 在新建库会失败（预期，仅告警）。
- 幂等：`CREATE TABLE IF NOT EXISTS`、`INSERT IGNORE`、`ALTER ... MODIFY`。
- **权限重构迁移**：`main.rs::migrate_direct_permissions` 在 `run_migrations` 后执行（仅当 `employee_permissions` 表仍存在）：
  1. 持有「全部存量权限码（排除 role:manage）」的员工绑定 `super_admin`；
  2. 其余持有部分权限的员工生成私有角色（role id = 员工 id，scope=all）承载原权限；
  3. 全员 `perm_version + 1` 强制重算；
  4. `DROP TABLE employee_permissions`（下次启动表不存在则跳过）。
- **敏感字段加密迁移**：`main.rs` 中 `migrate_sensitive_fields` 在 `run_migrations` 后执行——对 `employees` 表中无 `enc:v1:` 前缀的 `email/phone/id_number/address` 明文加密回写（幂等）。

## 五、特殊字段语义

| 字段 | 语义 |
| --- | --- |
| employees.status | 1 启用；非 1 禁用。登录拒绝、已签发令牌立即失效 |
| employees.pwd_version | 密码版本号。改密/重置/首登激活时递增，令牌失效（全端踢出） |
| employees.active_session | 当前会话 id。登录/首登覆盖，旧设备令牌 `sid` 失配即被顶下线（单设备登录） |
| employees.perm_version | **权限版本号**。角色权限/继承/范围、员工角色分配、部门角色绑定、员工部门归属、部门结构变更时递增；令牌内版本与库不一致即由中间件重算有效授权（即时生效） |
| employees.preferences | 个人偏好 JSON（TEXT），白名单字段 |
| roles.scope_type | all/subtree/department/self/custom（数据范围，见 `权限系统设计.md` §5） |
| roles.is_system | 1=内置角色（super_admin）不可删除/改权限/改范围 |
| conversations.type | single / group |
| messages.type | text / file |
| conversation_participants.role | member / admin（群管理要求 admin） |
| token_blacklist.jti | 登出与 refresh 轮换时记录，命中即 401（40003） |

# Manner_Web 数据库设计

> 本文件以 `backend/sql/init.sql` 为**唯一权威依据**，2026-08 核对；后端启动时重放该脚本（见「迁移机制」）。
> 相关文档：[权限系统设计.md](./权限系统设计.md) · [API文档.md](./API文档.md)。

---

## 一、概述

- 数据库：MySQL 8；字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`；存储引擎 InnoDB。
- 主键约定：
  - 业务实体（员工、会话、消息、拉黑、黑名单记录）用 `CHAR(36)` UUID 主键，由应用层生成；
  - `permissions` 用自增 `INT`；
  - `system_settings` 用业务字符串键（`setting_key`）。
- 时间约定：时间列使用 `DATETIME`；`created_at` 默认 `CURRENT_TIMESTAMP`；`updated_at` 带 `ON UPDATE CURRENT_TIMESTAMP` 自动更新。
- **共 9 张表**，分五组：

| 分组 | 表 |
| --- | --- |
| 组织与账号 | employees |
| 权限 | permissions、employee_permissions |
| 会话安全 | token_blacklist |
| 聊天 | conversations、conversation_participants、messages、blocked_users |
| 系统配置 | system_settings |

> 无部门表、无角色表；权限为员工级直接授权（见 [权限系统设计.md](./权限系统设计.md)）。

## 二、表结构

### 2.1 employees（员工账号）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| username | VARCHAR(64) | UNIQUE, NOT NULL | 登录用户名 |
| password | VARCHAR(255) | NOT NULL | bcrypt 哈希（cost 12），不存明文 |
| name | VARCHAR(64) | NOT NULL | 姓名 |
| title | VARCHAR(64) | NULL | 职位 |
| email | VARCHAR(128) | NULL | 邮箱 |
| phone | VARCHAR(20) | NULL | 电话 |
| id_number | VARCHAR(18) | NULL | 身份证号 |
| address | VARCHAR(255) | NULL | 地址 |
| hire_date | DATE | NULL | 入职日期 |
| status | TINYINT | NOT NULL DEFAULT 1 | 1 启用 / 非 1 禁用（见「特殊字段语义」） |
| pwd_version | INT | NOT NULL DEFAULT 0 | 密码版本号（改密递增，全端踢出） |
| must_change_password | TINYINT | NOT NULL DEFAULT 0 | 1=首登强制改密 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| avatar | VARCHAR(255) | NULL | 头像 URL（/uploads/...） |
| updated_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| protect_block | TINYINT | NOT NULL DEFAULT 0（ALTER 追加） | 防拉黑保护（1=保护） |
| preferences | TEXT | NULL（ALTER 追加） | 个人偏好 JSON（白名单 schema） |

索引：`PRIMARY KEY(id)`、`UNIQUE(username)`、`idx_status(status)`、`idx_name(name)`。**无外键**。

### 2.2 permissions（权限字典）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | INT | AUTO_INCREMENT PK | 自增主键 |
| code | VARCHAR(64) | UNIQUE, NOT NULL | 权限码，如 employee:list |
| name | VARCHAR(64) | NOT NULL | 权限名称 |
| module | VARCHAR(32) | NOT NULL | 所属模块（employee/chat/system） |

种子数据（`INSERT IGNORE`，共 11 条）：

| code | name | module |
| --- | --- | --- |
| employee:list | 查看员工列表 | employee |
| employee:view | 查看员工详情 | employee |
| employee:create | 新增员工 | employee |
| employee:edit | 编辑员工 | employee |
| employee:delete | 删除员工 | employee |
| employee:password | 重置员工密码 | employee |
| chat:protect_block | 防拉黑保护 | chat |
| chat:group_create | 群聊创建 | chat |
| chat:upload | 上传文件 | chat |
| system:config | 系统配置 | system |
| system:settings | 系统设置 | system |

另：脚本尾部执行 `DELETE FROM permissions WHERE code = 'employee:protect_block'`（清理历史废弃码），并幂等补插 `chat:group_create`、`system:settings`。

### 2.3 employee_permissions（员工-权限关联）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| employee_id | CHAR(36) | NOT NULL, 联合 PK | 员工 ID |
| permission_id | INT | NOT NULL, 联合 PK | 权限 ID |

外键：`employee_id → employees(id) ON DELETE CASCADE`、`permission_id → permissions(id) ON DELETE CASCADE`（**双外键级联**，删员工/删权限自动清理关联）。

### 2.4 token_blacklist（令牌黑名单）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| jti | VARCHAR(255) | UNIQUE, NOT NULL | JWT 的 jti 声明（登出/轮换时记录） |
| expires_at | DATETIME | NOT NULL | 令牌过期时间（黑名单条目过期即失效） |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 记录时间 |

索引：`idx_jti(jti)`、`idx_expires_at(expires_at)`。独立表，无外键。

### 2.5 conversations（会话）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| type | VARCHAR(16) | NOT NULL DEFAULT 'single' | single=单聊 / group=群聊 |
| name | VARCHAR(128) | NULL | 群聊名称（单聊为 NULL） |
| created_by | CHAR(36) | NULL | 创建者员工 ID（逻辑引用） |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |

无外键。单聊会话由「创建员工」接口自动生成（`INSERT IGNORE`，幂等）。

### 2.6 conversation_participants（会话参与人）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| conversation_id | CHAR(36) | NOT NULL, 联合 PK | 会话 ID |
| employee_id | CHAR(36) | NOT NULL, 联合 PK | 员工 ID |
| joined_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 加入时间 |
| role | VARCHAR(16) | NOT NULL DEFAULT 'member' | member / admin（群管理员） |
| nickname | VARCHAR(64) | NULL | 本会话内昵称 |
| group_note | VARCHAR(255) | NULL | 我为对方设置的单聊备注 |

无外键（会话/员工删除时由应用层处理或保留脏数据容忍策略）。

### 2.7 messages（消息）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| id | CHAR(36) | PK | UUID 主键 |
| conversation_id | CHAR(36) | NOT NULL | 所属会话（逻辑引用） |
| sender_id | CHAR(36) | NOT NULL | 发送者员工 ID（逻辑引用） |
| type | VARCHAR(16) | NOT NULL DEFAULT 'text' | text / file |
| content | TEXT | NULL | 文本内容 |
| file_url | VARCHAR(512) | NULL | 文件消息链接（/uploads/chat/...） |
| file_name | VARCHAR(256) | NULL | 原始文件名 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 发送时间 |

索引：`idx_conversation_time(conversation_id, created_at)`（会话内按时间拉取）。**无外键**。

### 2.8 system_settings（系统设置）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| setting_key | VARCHAR(64) | PK | 业务字符串键 |
| setting_value | TEXT | NOT NULL | 值 |
| updated_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

种子（`INSERT IGNORE`）：`registration_open='1'`（首个管理员注册开关）、`login_max_failures='5'`、`login_lock_window_secs='900'`（登录限流参数）。运行时键：`chat_upload_limit`、`login_theme`、`site_title`、`login_site_title` 等。

### 2.9 blocked_users（拉黑关系）

| 列名 | 类型 | 约束/默认 | 说明 |
| --- | --- | --- | --- |
| blocker_id | CHAR(36) | NOT NULL, 联合 PK | 拉黑发起者 |
| blocked_id | CHAR(36) | NOT NULL, 联合 PK | 被拉黑者 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 拉黑时间 |

无外键；语义为「双向」（A 拉黑 B 与 B 拉黑 A 是两条独立记录，单聊发消息时校验「对方是否拉黑我」）。

## 三、表间关系

```
employees ──< employee_permissions >── permissions      （多对多，双外键 CASCADE）
    │                                        │
    │  (无外键，逻辑引用)                      │
    ▼                                        ▼
conversations ──< conversation_participants >── employees（多对多；role: member/admin）
    │
    └──< messages          （messages 归属会话与发送者，无 FK）
blocked_users（blocker_id ↔ blocked_id，双向语义，无 FK）
token_blacklist（独立表，与任何表无关联）
system_settings（独立键值表）
```

- `employees ↔ permissions`：多对多，经 `employee_permissions` 关联，权限直接授予员工（无角色中间层）。
- `conversations ↔ employees`：多对多，经 `conversation_participants` 关联；`messages` 通过 `conversation_id` / `sender_id` 逻辑归属会话与发送者（**无外键**）。
- `blocked_users`：拉黑关系自关联员工，双向语义（`blocker_id` 与 `blocked_id` 均逻辑引用 `employees.id`，无外键）。
- `token_blacklist`：独立，仅存注销的令牌 jti 与过期时间。
- `system_settings`：键值存储，独立。

## 四、迁移机制

- 后端启动时执行 `run_migrations`：读取 `include_str!("../sql/init.sql")`，按 `;` 分号分割逐条执行。
- 跳过 `CREATE DATABASE` / `USE` 语句（数据库由外部准备，连接串 `DATABASE_URL` 指定）。
- 单条语句失败**仅 warn 不中断**启动（保证存量库可继续启动）。
- 幂等设计：`CREATE TABLE IF NOT EXISTS`、`INSERT IGNORE`（种子数据），重复启动安全。
- **非版本化**：无迁移版本表；历史演进通过追加 `ALTER TABLE` 实现（如 `protect_block`、`preferences` 列），此类语句不幂等但失败仅告警。
- 维护约定：新增列优先在 `init.sql` 尾部追加 `ALTER TABLE`（或同步修改 CREATE TABLE 并保留幂等补丁）；删除历史废弃数据使用显式 `DELETE`（如废弃权限码清理）。

## 五、特殊字段语义

| 字段 | 语义 |
| --- | --- |
| employees.status | 1 启用；非 1 禁用。登录时拒绝（统一 40001 不区分）；令牌校验要求 `status=1`，禁用后已签发令牌立即失效 |
| employees.pwd_version | 密码版本号。本人改密、管理员重置、首登激活时递增；令牌内含签发时版本，与库不一致即失效（全端踢出） |
| employees.must_change_password | 首登强制改密标记。创建员工/重置密码时置 1，经 `first-login` 激活后置 0；`precheck` 仅对该状态返回 true |
| employees.protect_block | 防拉黑保护。置 1 后禁止被删除/禁用/改密/改权/拉黑（本人改自己头像除外）；经 `chat:protect_block` 权限管理 |
| employees.preferences | 个人偏好 JSON（TEXT），仅接受白名单字段（theme/timezoneMode/timezoneOffset/newConvPosition），未知字段丢弃 |
| conversations.type | single=单聊（创建员工自动生成）/ group=群聊 |
| messages.type | text=文本 / file=文件（必须携带合法 file_url） |
| conversation_participants.role | member=普通成员 / admin=群管理员（群管理操作要求 admin；单聊无角色概念） |
| token_blacklist.jti | 登出与 refresh 轮换时记录，命中即 401（40003） |

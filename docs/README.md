# Manner_Web 文档

> Manner_Web 是一个面向企业内部的 Web 管理系统：员工管理 + 员工级直接授权 + 站内聊天（单聊/群聊、文本/文件消息、拉黑）+ 系统设置（登录页、上传限制、登录限流），基于 Rust + SvelteKit 构建。

本文档目录（`docs/`）是 Manner_Web 的文档入口页。项目整体介绍、环境配置与本地开发命令请参见[根 README](../README.md)。
